## 今天为什么学这个（20 分钟）

环境差异包括 URL、日志级别和资源预算，秘密是其中需要特殊保护的一类。示例文件列变量名与含义，不提供真实生产值。

把今天的知识放回 Atlas：你要交付的是下面这组能复现的行为，而不只是记住术语。实验使用虚构设备与测试数据，路径以仓库根为基准；Bash 与 PowerShell 的区别见环境说明。

## 跟着完成（70 分钟）

1. 列出 DATABASE_URL、模型配置、存储路径与必填项

2. 使用环境变量或配置模块读取，缺失关键项时启动明确报错

3. 检查 Git 忽略规则及历史中的敏感文件，只把 .env.example 入库

## 观察结果与验收（10 分钟）

dev 和测试 production 使用独立数据与凭据，前端 bundle 不包含后台 key。

保存输入、实际输出、使用的版本和耗时。实际结果不符合预期时，先保留原始错误，再检查本日涉及的配置与数据；不要同时修改多个变量。

## 故障实验（15 分钟）

漏掉模型 key，确认在使用相关能力前得到清晰配置错误，而不是将空字符串发往上游。

完成后撤销故障注入，重复正常路径。涉及删除、停服务、断网、OOM 的实验只在可恢复的隔离测试环境执行；没有条件时用模拟错误，不对正在使用的系统操作。
