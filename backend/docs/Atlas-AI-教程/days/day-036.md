## 今天为什么学这个（20 分钟）

Compose 把手工 run 参数变成可审阅的配置。网络、卷、环境与依赖共同定义服务栈；配置可解析不表示所有服务都已可用。

把今天的知识放回 Atlas：你要交付的是下面这组能复现的行为，而不只是记住术语。实验使用虚构设备与测试数据，路径以仓库根为基准；Bash 与 PowerShell 的区别见环境说明。

## 跟着完成（70 分钟）

1. 按手册建立 deployment/compose.yaml，先用固定版本 PostgreSQL 与 Redis

2. 运行 docker compose --env-file .env.lab config 检查变量解析，注意输出可能含秘密

3. 运行 up -d 后查看 ps、logs，记录服务名和持久卷
