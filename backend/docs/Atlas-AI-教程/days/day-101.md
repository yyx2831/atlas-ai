## 今天为什么学这个（20 分钟）

vLLM 是独立推理服务，应在官方支持的 Linux 与硬件组合上安装。业务 FastAPI 通过 HTTP 调用，避免模型生命周期与业务进程耦合。

把今天的知识放回 Atlas：你要交付的是下面这组能复现的行为，而不只是记住术语。实验使用虚构设备与测试数据，路径以仓库根为基准；Bash 与 PowerShell 的区别见环境说明。

## 跟着完成（70 分钟）

1. 核对所选 vLLM 版本的 GPU、驱动与 Python 要求，记录固定版本

2. 在独立环境或官方镜像运行许可允许的小模型，查看 vllm serve --help 后设置实际参数

3. 用 /v1/models 验证服务模型列表，再发最小聊天请求
