## 今天为什么学这个（20 分钟）

127.0.0.1 只接收当前网络命名空间的回环连接，0.0.0.0 表示所有 IPv4 接口。监听地址不是客户端应填写的目的地址。

把今天的知识放回 Atlas：你要交付的是下面这组能复现的行为，而不只是记住术语。实验使用虚构设备与测试数据，路径以仓库根为基准；Bash 与 PowerShell 的区别见环境说明。

## 跟着完成（70 分钟）

1. 让练习 API 绑定 127.0.0.1:8001，使用 ss -lntp 检查

2. 在允许的本地测试网络改绑 0.0.0.0，分别从本机和另一测试客户端访问主机实际 IP

3. 把监听、防火墙与客户端 URL 三项分别记录

## 观察结果与验收（10 分钟）

能解释本机可访问而另一机器不能访问的至少三种原因；测试后恢复局域网暴露设置。

保存输入、实际输出、使用的版本和耗时。实际结果不符合预期时，先保留原始错误，再检查本日涉及的配置与数据；不要同时修改多个变量。

## 故障实验（15 分钟）

用错误端口访问得到拒绝，再用正确端口复测；不把拒绝误判为 DNS 问题。

完成后撤销故障注入，重复正常路径。涉及删除、停服务、断网、OOM 的实验只在可恢复的隔离测试环境执行；没有条件时用模拟错误，不对正在使用的系统操作。
