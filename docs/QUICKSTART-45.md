# 45 天代码导读：每天跑一个结果，再改一处

这份教程配套的是已经落地的完整代码。你不必先读完所有文件：每天约 45～90 分钟，先运行，顺着一条调用链看源码，做一个小改动，最后记录证据。原 Day 14～19、21 已读理论，不自动等于已掌握代码。

启动命令见根 README。下面路径以仓库为根；仅写 `app/` 的路径位于 backend。每晚结束前在自己的笔记写三句：今天跑通了什么、改了哪里、还解释不清什么。需要 Docker/GPU 的课等环境可用时实做，不能用演示结果代替。

建议第一晚先完整跑“登录→知识问答→故障分析”，建立整体印象，再逐日回到实现。不要一次性阅读整个 services 目录。
