## 今天为什么学这个（20 分钟）

RAG 先找资料再生成，模型并不会自动知道哪些资料可信。把检索结果明确标为证据材料，回答不足时应说明缺少依据。

把今天的知识放回 Atlas：你要交付的是下面这组能复现的行为，而不只是记住术语。实验使用虚构设备与测试数据，路径以仓库根为基准；Bash 与 PowerShell 的区别见环境说明。

## 跟着完成（70 分钟）

1. 组合 query embedding→Top5→上下文→LLM，先不引入框架

2. 上下文逐块附可验证编号，限制总 token 预算

3. prompt 要求依据材料回答并返回引用编号，外部文档中的指令当数据处理

## 观察结果与验收（10 分钟）

能回答材料中存在的问题；材料没有答案时明确不足，不用模型常识伪装私有手册依据。

保存输入、实际输出、使用的版本和耗时。实际结果不符合预期时，先保留原始错误，再检查本日涉及的配置与数据；不要同时修改多个变量。

## 故障实验（15 分钟）

检索空集时调用回答逻辑，确认走“无足够资料”分支，避免硬编引用。

完成后撤销故障注入，重复正常路径。涉及删除、停服务、断网、OOM 的实验只在可恢复的隔离测试环境执行；没有条件时用模拟错误，不对正在使用的系统操作。

## 独立练习与自测

RAG 并未微调模型，为什么仍能回答新上传文档？

先写自己的解释，再对照概念段和官方资料。能复述定义但无法解释实验现象，进度仍标为「练习中」。
