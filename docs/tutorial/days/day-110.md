## 今天为什么学这个（20 分钟）

模型服务包含多个管理或诊断端点，不能把单个 API key 视为所有端点的完整保护。网络隔离、入口认证与最小路由共同形成边界。

把今天的知识放回 Atlas：你要交付的是下面这组能复现的行为，而不只是记住术语。实验使用虚构设备与测试数据，路径以仓库根为基准；Bash 与 PowerShell 的区别见环境说明。

## 跟着完成（70 分钟）

1. 根据固定版本官方安全说明枚举开放端点

2. 让模型服务只在内网可达，由 Atlas 使用受限入口

3. 从未授权测试客户端验证访问被拒，合法客户端才可推理

## 观察结果与验收（10 分钟）

监控、调试与模型服务不直接暴露公网，日志不泄露请求密钥。

保存输入、实际输出、使用的版本和耗时。实际结果不符合预期时，先保留原始错误，再检查本日涉及的配置与数据；不要同时修改多个变量。

## 故障实验（15 分钟）

绕过反代直连测试上游，确认网络规则同样限制访问。

完成后撤销故障注入，重复正常路径。涉及删除、停服务、断网、OOM 的实验只在可恢复的隔离测试环境执行；没有条件时用模拟错误，不对正在使用的系统操作。
