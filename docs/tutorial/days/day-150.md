## 今天为什么学这个（20 分钟）

安装脚本应检测前置、校验包、分步执行并给出失败原因；幂等是重复执行不会破坏数据。默认 root 并不能替代权限设计。

把今天的知识放回 Atlas：你要交付的是下面这组能复现的行为，而不只是记住术语。实验使用虚构设备与测试数据，路径以仓库根为基准；Bash 与 PowerShell 的区别见环境说明。

## 跟着完成（70 分钟）

1. 编写 install.sh 使用 set -euo pipefail，先检查架构、磁盘、Docker 和包校验

2. 分离 privileged 前置操作与普通部署，检测已有卷避免覆盖

3. 在空测试机执行两遍，并提供日志和明确失败退出码

## 观察结果与验收（10 分钟）

首次安装完成，第二次不重置数据库、不重复造凭据；缺前置时在修改系统前停止。

保存输入、实际输出、使用的版本和耗时。实际结果不符合预期时，先保留原始错误，再检查本日涉及的配置与数据；不要同时修改多个变量。

## 故障实验（15 分钟）

破坏离线包副本的校验和，确认脚本拒绝继续，换回正确包后成功。

完成后撤销故障注入，重复正常路径。涉及删除、停服务、断网、OOM 的实验只在可恢复的隔离测试环境执行；没有条件时用模拟错误，不对正在使用的系统操作。
