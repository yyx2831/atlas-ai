## 今天为什么学这个（20 分钟）

TS 类型注解编译后消失，Python 注解通常也不会自动校验。list 可变，tuple 不可直接修改元素，dict 是键值映射；业务输入校验另交给 Pydantic。

把今天的知识放回 Atlas：你要交付的是下面这组能复现的行为，而不只是记住术语。实验使用虚构设备与测试数据，路径以仓库根为基准；Bash 与 PowerShell 的区别见环境说明。
