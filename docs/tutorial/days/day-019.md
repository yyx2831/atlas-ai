## 今天为什么学这个（20 分钟）

ORM 把行映射成对象，Session 管理工作单元，并不等于数据库本身。select 与 scalars 返回模型对象；flush 发 SQL，commit 才提交事务。

把今天的知识放回 Atlas：你要交付的是下面这组能复现的行为，而不只是记住术语。实验使用虚构设备与测试数据，路径以仓库根为基准；Bash 与 PowerShell 的区别见环境说明。
