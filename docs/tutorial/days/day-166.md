## 今天为什么学这个（20 分钟）

README 先回答解决什么问题、如何最快体验，再链接深入文档。演示截图和功能声明必须对应实际能力。

把今天的知识放回 Atlas：你要交付的是下面这组能复现的行为，而不只是记住术语。实验使用虚构设备与测试数据，路径以仓库根为基准；Bash 与 PowerShell 的区别见环境说明。

## 跟着完成（70 分钟）

1. 编写背景、目标用户、已实现功能、架构、快速开始与部署入口

2. 提供 mock 无 GPU 路径与实机路径，明确区别

3. 在全新终端按 Quick Start 一次走通，修正缺失前提

## 观察结果与验收（10 分钟）

不了解作者的人能启动并理解限制，未完成能力没有勾成完成。

保存输入、实际输出、使用的版本和耗时。实际结果不符合预期时，先保留原始错误，再检查本日涉及的配置与数据；不要同时修改多个变量。

## 故障实验（15 分钟）

让同伴只看 README 尝试运行，记录第一处卡点并修订。

完成后撤销故障注入，重复正常路径。涉及删除、停服务、断网、OOM 的实验只在可恢复的隔离测试环境执行；没有条件时用模拟错误，不对正在使用的系统操作。
