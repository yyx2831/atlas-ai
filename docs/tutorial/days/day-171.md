## 今天为什么学这个（20 分钟）

定位应匹配可证明能力，前端背景是系统交付优势，不需要虚构专家身份。学习项目与商业项目应明确区分。

把今天的知识放回 Atlas：你要交付的是下面这组能复现的行为，而不只是记住术语。实验使用虚构设备与测试数据，路径以仓库根为基准；Bash 与 PowerShell 的区别见环境说明。

## 跟着完成（70 分钟）

1. 写一页简历，按经历、技能、项目与教育组织

2. Atlas 标明个人学习实作项目，列实际完成阶段

3. 每项技能附能解释或演示的证据，删除只听过名词的熟练声明

## 观察结果与验收（10 分钟）

履历真实，联系方式与公开仓库可用，未完成的 GPU 验证不写成生产经验。

保存输入、实际输出、使用的版本和耗时。实际结果不符合预期时，先保留原始错误，再检查本日涉及的配置与数据；不要同时修改多个变量。

## 故障实验（15 分钟）

请朋友追问一条技能，答不出时降低表述或补实作，不增加夸大措辞。

完成后撤销故障注入，重复正常路径。涉及删除、停服务、断网、OOM 的实验只在可恢复的隔离测试环境执行；没有条件时用模拟错误，不对正在使用的系统操作。

## 独立练习与自测

你与只会调用模型 API 的候选人相比，哪些具体交付证据不同？

先写自己的解释，再对照概念段和官方资料。能复述定义但无法解释实验现象，进度仍标为「练习中」。
