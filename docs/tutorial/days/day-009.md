## 今天为什么学这个（20 分钟）

Depends 由 FastAPI 在请求中解析，普通函数调用不会自动执行依赖。yield 前创建资源、finally 关闭资源；service 接收显式 Session 更容易独立测试。

把今天的知识放回 Atlas：你要交付的是下面这组能复现的行为，而不只是记住术语。实验使用虚构设备与测试数据，路径以仓库根为基准；Bash 与 PowerShell 的区别见环境说明。
