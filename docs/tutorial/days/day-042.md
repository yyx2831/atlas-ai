## 今天为什么学这个（20 分钟）

SSE 是文本事件流，网络分块不是 token 边界也不是 JSON 边界。POST 聊天通常用 fetch 读取流，浏览器 EventSource 原生主要用于 GET。

把今天的知识放回 Atlas：你要交付的是下面这组能复现的行为，而不只是记住术语。实验使用虚构设备与测试数据，路径以仓库根为基准；Bash 与 PowerShell 的区别见环境说明。
