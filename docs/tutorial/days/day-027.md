## 今天为什么学这个（20 分钟）

交互终端退出会影响手工进程，systemd 用 unit 明确用户、目录、环境和重启策略。服务环境不继承你的交互 shell 配置。

把今天的知识放回 Atlas：你要交付的是下面这组能复现的行为，而不只是记住术语。实验使用虚构设备与测试数据，路径以仓库根为基准；Bash 与 PowerShell 的区别见环境说明。

## 跟着完成（70 分钟）

1. 确认测试 Linux 的 PID 1 是 systemd，WSL 未启用时先使用 VM 或按官方文档启用

2. 用配套环境示例写 atlas-api.service，明确 WorkingDirectory 与 .venv/bin/uvicorn 绝对路径

3. daemon-reload 后 start，查看 status 与 journalctl -u atlas-api
