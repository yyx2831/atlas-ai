## 每晚怎么用

先花 10 分钟读原理，20 分钟读关键代码，20 分钟运行与改动，最后 10 分钟回答自测。某天需要 90 分钟也正常；不必为了“Day N”跳过没有理解的部分。

每章都有：要解决的问题 → 原理 → 关键代码 → 运行命令 → 预期现象 → 对照 Atlas → 小练习 → 验收。看不懂 Python 的地方会用 TypeScript 习惯解释。

## 三种实验，别混为一谈

**离线回放**：`learn.py` 默认使用虚构设备和固定模型响应。无需启动后端、无需 API Key；用来验证程序如何执行，不证明模型聪明。

**真实模型 + 虚构工具数据**：显式加 `--real`，模型才会真正决定是否调用工具。设备数据仍来自 labs 的内存字典，便于隔离变量。请求可能产生你所配置服务的费用。

**Atlas 集成**：Day 24 访问你本地正在运行的 Atlas，使用真实登录身份、现有设备/手册和后台配置的模型。演示模式下模型仍是固定回放，但 API、数据库和 MCP 都是真实链路。

## 版本范围

教程对照 2026-09-23 的项目源码。Python 3.12+；项目安装的 LangGraph 1.2.x、MCP Python SDK 1.30.0，依赖约束是 `mcp>=1.26,<2`。不要为了跟教程运行就升级到新主版本。

本文 MCP 代码使用项目已锁定的 **1.x SDK 会话初始化接口**。协议与 SDK 是两种版本号；官网最新页面可能描述另一代发现流程，不能直接混搭。相关版本资料在最后一章。
